# 📖 NextWord

🚧 Working Progress 🚧

NextWord is a from-scratch neural network that learns from a given text input
and predicts the next word. Given a single word, it returns the top 5 most
probable next words.

## Why This Project

This project focuses on understanding the fundamentals of training language
models using only core python and numpy instead of using deep learning frameworks.

## Quick Start

```bash
# clone this repo
git clone https://nick-ob/nextword
cd nextword

# install requirements
pip install -r requirements.txt
```

## Tech Stack

- **Python**
- **NumPy**
